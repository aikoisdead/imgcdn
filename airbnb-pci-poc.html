What this means

Every message above was sent by the genuine Airbnb PCI card iframe via postMessage(data, targetOrigin), where targetOrigin was set to this page's origin () instead of https://www.airbnb.com.

The browser only delivers a postMessage when the recipient's actual origin matches the targetOrigin. The fact that this non-Airbnb page received these messages proves the iframe is using the attacker-controlled ?origin= parameter as its targetOrigin.

When a user types a card number into this iframe, the binReady event sends the first 6 digits (BIN) to whatever origin loaded the iframe. The tokenizeResponse sends the full card token. This is PCI cardholder data leaving the hosted field to an unauthorized origin.
