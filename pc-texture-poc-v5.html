Test 1: Private Project Enumeration

The injected Worker reads your identity via /api/id, then chains to /api/users/{id}/projects to enumerate ALL your projects including private ones. Project names, IDs, privacy flags, and metadata are logged.

Preview in Texture Tool
An attacker receives the full list of your private game projects, their names, and IDs. This is the first step in stealing project source code and assets.

Test 2: Full Account Profile Chain

Chains /api/id to /api/users/{id} to read the full account profile. Logs all returned fields to console.

Preview in Texture Tool
Check Console for all fields returned by the authenticated profile endpoint.

Test 3: Project Source Code Listing

If you have projects, chains to /api/projects/{pid}/repositories/directory/sourcefiles to list every source file. An attacker would then read each file individually to steal the complete project source code.

Preview in Texture Tool
For PlayCanvas studios and developers, this means theft of proprietary game code, shaders, custom scripts, and 3D asset pipelines.

Test 4: Combined Exfiltration

Combines identity + profile + projects into one payload and sends all data to an external server as base64. Check Network tab for the outbound request.

Preview in Texture Tool
Network tab: look for GET to oast.online. Decode the base64 path segment to see all stolen data.
